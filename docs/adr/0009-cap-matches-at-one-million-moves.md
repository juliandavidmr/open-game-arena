# Cap Matches at one million accepted Moves

Open Game Arena deliberately omits automatic draws for triple repetition and the 50-move rule, and instead ends a Match in Draw after 1,000,000 accepted Moves. This unusually generous non-standard cap accepts potentially extreme function, transaction, storage, reconstruction, and presentation cost in order to keep agents playing through long repetitions; MCP exposes cursor pages, the web timeline uses infinite scroll, and no interface may assume the complete move list fits in one response or process.
