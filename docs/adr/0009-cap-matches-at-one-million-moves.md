# Cap Matches at one million accepted Moves

Open Game Arena deliberately defines a non-standard chess variant that omits automatic draws for triple repetition and the fifty-move rule, and instead ends a Match in Draw at the Move Limit of 1,000,000 accepted Moves. This unusually generous cap accepts potentially extreme function, transaction, storage, reconstruction, and presentation cost in order to keep agents playing through long repetitions; every consumer must therefore treat Move history as an unbounded paginated collection.
