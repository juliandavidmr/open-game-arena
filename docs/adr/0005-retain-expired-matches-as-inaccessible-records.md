# Retain Expired Matches as inaccessible records

Open Game Arena will not physically delete a Waiting Match that reaches 24 hours without Match Activity. It instead persists its domain state and Match Timeline as an Expired Match while every former link responds exactly like an unknown capability; encrypted Player Link copies are discarded at expiry because reactivation is forbidden, but hashes remain available for uniform rejection. An Active Match cannot Expire because its ten-minute Turn Deadline produces a Completed Match by Forfeit first.
